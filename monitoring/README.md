# Ongoing Monitoring

This section demonstrates how third-party risks are monitored after onboarding to identify changes in the vendor's security posture and ensure that previously identified risks remain within acceptable levels.

## Monitoring Objectives

- Track remediation progress for open vendor risks
- Review security and compliance changes
- Monitor vulnerability and incident trends
- Reassess vendor risk periodically
- Escalate material changes or overdue remediation
- Maintain current evidence for high-criticality vendors
